# Demo

## Introduction

This is a spring boot application for a demo

## Getting started

### Prerequisites

- Java 17
- Maven

### Installation

1. Clone the repository
2. Run `mvn clean install`

### Usage

1. Run the application with `java -jar target/demo-0.0.1-SNAPSHOT.jar`
2. Open your browser and navigate to `http://localhost:8080`
